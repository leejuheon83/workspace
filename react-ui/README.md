# E-hub (React + Tailwind redesign)

`EHubRedesign` 컴포넌트 미리보기용 Vite 앱입니다. 루트의 `index.html` 정적 포털과는 별도로 동작합니다.

## 실행

```bash
cd react-ui
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## Vercel 배포

프로젝트 루트의 [docs/VERCEL.md](../docs/VERCEL.md) 를 참고하세요. CLI만 쓸 때:

```bash
npm run deploy:vercel       # 프리뷰
npm run deploy:vercel:prod  # 프로덕션
```
